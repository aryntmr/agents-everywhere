## Judging criteria

Judged globally after submissions close. Each criterion scored **1–5**; no weights published.

1. **Core Requirements & Functionality** — a working agent *inside* a place people already work/talk/live; core workflow runs end to end. 3 = basic end-to-end with bugs; 5 = robust and fully functional in its environment.
2. **Innovation & Theme Alignment** — does the environment materially improve what the agent can do? 1 = generic chatbot, environment irrelevant; 2 = environment is just a wrapper; 5 = a surprising agent pattern whose value *couldn't* exist in a standalone chatbox.
3. **Technical Execution & Integration** — code, architecture, reliability, tool use, data handling, depth of integration. 1 = conceptual or mocked; 5 = robust orchestration, thoughtful failure handling, deeply integrated.
4. **Usefulness & Agentic Experience** — clear value for real users; feels native to its environment; uses context intelligently while staying clear and controllable. 2 = basically prompt-and-response.

**What this means:** the environment has to be load-bearing, integrations must be real (not mocked), and the agent must *act*, not just reply.
